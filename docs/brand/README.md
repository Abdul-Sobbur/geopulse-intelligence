# GeoPulse brand

The mark is a single pulse line that also reads as river flow, with a dot for a satellite or sensor.

| File | Use |
| --- | --- |
| `geopulse-logo-on-dark.svg` | Logo for dark backgrounds (transparent) |
| `geopulse-logo-on-light.svg` | Logo for light backgrounds, including the README (transparent) |
| `geopulse-logo-dark-tile.svg` | Logo with its own night-blue background |
| `geopulse-mark.svg` | The mark on its own (avatars, small spaces) |
| `social-preview.png` | GitHub repository card, 1280 x 640 |
| `../../frontend/public/favicon.svg` | Browser tab icon |

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Night blue | `#0E1B26` | Backgrounds, wordmark on light |
| Cyan | `#22D3EE` | The mark on dark backgrounds |
| Deep cyan | `#0891B2` | The mark on light backgrounds (cyan is too pale on white) |
| Off-white | `#E6EEF3` | Wordmark on dark |

## Rules

- The wordmark is Barlow Condensed SemiBold, converted to outlines so it looks the same everywhere.
- Keep clear space around the logo at least the height of the dot.
- Do not stretch, recolour, add effects, or place the cyan mark on light backgrounds.

The SVGs are generated by `scripts/make_logo.py` (needs `fonttools` and the Barlow Condensed 600 font file from the `@fontsource/barlow-condensed` package).
